# Здоровье

Отдельное приложение раздела «Здоровье». Это копия модуля из `cher-no-pr-copy`. Исходный проект не изменялся.

Тренировки, привычки, прогресс и профиль. Данные хранятся в браузере. Если API исходного проекта запущен на порту 3001, синхронизация подключается сама.

## Запуск

Дважды щёлкните `start.bat` или в этой папке выполните:

```powershell
npm install
npm start
```

Браузер откроется на http://localhost:5174

Приложение работает само: тренировки и привычки сохраняются в браузере. Сервер исходного проекта не нужен.
