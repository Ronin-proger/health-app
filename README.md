# health-app

Трекер тренировок и привычек. Открывается в браузере и как Telegram Mini App. Записи остаются на устройстве, пока не задан адрес своего API.

## Как выглядит

Главная с планом на день, карта мышц и готовые программы.

![Главная, карта мышц, программы](docs/screens/slide-06.png)

Карта нагрузки, живой подход, программы, разбор упражнения, графики, рекорды и шаги.

![Карта, подход, графики](docs/screens/slide-07.png)

План дня, вес, параметры тела, фото прогресса, настройки и PDF-отчёт.

![Профиль и отчёт](docs/screens/slide-08.png)

## Что умеет

- **Главная.** Серия, неделя, план на сегодня, шаги, вода, сон.
- **Карта мышц.** Тело спереди и сзади. Цвет группы зависит от объёма тренировок, а не от ручной отметки.
- **Тренировки.** Программы по жиму, тяге, ногам и кору, библиотека с техникой, свой план.
- **Живая сессия.** Подходы, вес, повторы, таймер отдыха. Новый личный рекорд отмечается в момент записи.
- **Прогресс.** Неделя, месяц и год: калории, объём, фокус по мышцам, рекорды. Выгрузка в CSV и PDF собирается в браузере.
- **Профиль.** Уровень, цель по весу, замеры, фото прогресса, тема, напоминание о тренировке.
- **Два языка.** Русский и английский, метрические и имперские единицы.

## Данные

Состояние — один версионированный документ в `localStorage`. Фото прогресса хранятся как data URL и в синхронизацию не попадают.

Без `VITE_API_URL` сеть не нужна. С адресом клиент отправляет последние 350 подходов и 64 сессии. Слияние — объединение по id записи, локальная копия важнее. Счётчики берутся по максимуму, дневник — более новый. Внутри Telegram к запросу добавляется `initData`. Если ответ не пришёл за 4 секунды, на экране остаются локальные данные.

```text
браузер или Telegram
        │
        ▼
React / Vite :5174
        ├── localStorage
        └── VITE_API_URL   необязательно
```

## Запуск

Нужен Node.js.

```bash
npm install
npm start
```

Приложение открывается на `http://localhost:5174`. На Windows то же самое делает `start.bat`.

```bash
npm test
npm run build
```

Адрес сервера, если он нужен, задаётся в `.env` по образцу `.env.example`.
